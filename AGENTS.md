# AGENTS.md: contributing to Christopher Nolan

This file is for agents and humans working **on** the tool. End users are guided by the skill (`skills/nolan/SKILL.md`), not by this file. `CLAUDE.md` imports this file (`@AGENTS.md`).

The contract is `docs/SPEC.md`. Verified research lives in `docs/research/*.md`; `critic.md` wins on conflicts. Read the relevant brief before touching an area.

## Commands

```bash
npm install                                  # Node >= 22.18
node cli/nolan.ts help                       # CLI (also: npm run nolan -- <cmd>)
node cli/nolan.ts doctor                     # environment check
npx tsc --noEmit                             # typecheck (must be clean)
npm test                                     # node --test "cli/test/*.test.ts"
npx remotion compositions src/index.ts       # list compositions
npx remotion studio src/index.ts --port=3123 # Studio (normally via: node cli/nolan.ts studio <slug>)
claude plugin validate .                     # plugin + marketplace manifests
```

Demo loop (end-to-end check):

```bash
node cli/nolan.ts validate christopher-nolan-trailer
node cli/nolan.ts audio all christopher-nolan-trailer
node cli/nolan.ts stills christopher-nolan-trailer        # then look at the PNGs
node cli/nolan.ts render christopher-nolan-trailer --draft
```

## Rules

- **Plain TypeScript run by Node's type stripping.** Erasable syntax only: no `enum`, no `namespace`, no parameter properties. `import type` for types. Relative imports end in `.ts`. No build step, no `tsx`.
- **Pins:** every `remotion` / `@remotion/*` package at exactly `4.0.530`; `zod@4.5.4`, `react@19.2.3`, `shiki@4.4.3`. No `^`. No new dependency unless the spec lists it.
- **Minimal code:** stdlib first, fewest files, no abstraction with one caller, no speculative options.
- **CLI output:** concise and agent-readable; every command ends with a `next:` line; failures exit non-zero with `error: <cause>` and `fix: <command>` (use `fail()` from `cli/lib/log.ts`). `--json` where useful.
- **Remotion:** pass `--props` as a file path, never inline JSON. Studio's 💾 only works with an inline `defaultProps` literal in `src/Root.tsx`; keep it generated. Derived props start with `_` and are stripped by `sync`.
- **ffmpeg:** prefer system `ffmpeg`/`ffprobe`, else Remotion's bundled one, which lacks `afade`, `ebur128` and lavfi. Fades and ducking belong in Remotion (`src/audio/Mix.tsx`).
- **Cross-platform:** `node:path` everywhere; forward slashes for `staticFile()` paths; spawn Node scripts directly instead of `npx` shims.
- **Licenses:** never accept NC or ND audio; CC BY-SA only on opt-in; every downloaded asset gets an `assets.lock.json` entry so the outro can credit it.
- **Secrets:** `OPENROUTER_API_KEY` lives in the environment or `~/.config/christopher-nolan/.env` (mode 600). Never log it, never write it into a project.
- **Tests:** only for non-trivial pure logic (ledger math, audio scoring, license filter, timing, sync literal extraction, schema defaults).
- **Skill:** `skills/nolan/SKILL.md` stays under 300 lines, `name` equals the directory name. Command names and flags in the skill must match `cli/nolan.ts` exactly; update both together.
- Code and docs in English.
